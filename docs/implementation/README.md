# Implementation documents

This directory holds the implementation requirements: how the code applies the design
requirements of a specification in [`docs/specs/`](../specs/README.md). An implementation
document also holds the cause of a defect, the tests, the deployment guidance, and the order
of delivery.

An implementation document does not add a user requirement or a design requirement. If an
implementation item needs a new rule, add the rule to the specification first.

You can change an implementation requirement freely when a better approach appears. Record
the change in the implementation document.
